About QR Lab

QR Lab is a lightweight, client-side QR code generator. Everything happens in your browser — nothing you type is sent anywhere.

URL & Text

Turn any link or block of text into a scannable code, updated as you type.

Wi-Fi

Share network access with a single scan — no typing passwords by hand.

Phone

Generate a code that opens the dialer with a number pre-filled.

Export

Download finished codes as crisp PNG or scalable SVG, at any size.

Built with HTML, CSS and vanilla JavaScript — no frameworks, no server, runs entirely on GitHub Pages.
